# Tracker-app
Mood Tracker — простой консольный трекер настроения на Python. Позволяет фиксировать эмоции (happy/ok/sad), сохранять их в CSV и строить базовую аналитику: общее количество записей, доли настроений, историю за последние 7 дней. Проект для тренировки работы с файлами, датами и статистикой.
