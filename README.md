# Mood Tracker 

Консольный трекер настроения на Python.

## Что делает

- Принимает ввод настроения: `happy`, `ok`, `sad`.
- Сохраняет дату и настроение в CSV-файл.
- Показывает статистику: количество по категориям, долю happy, историю за последние 7 дней.

## Как запустить

```bash
python mood_tracker.py
